Labs 1 and 2

What I Learned

  1. Basic HTML tags and formatting. Though we haven't yet explored the deeper and more complex aspects of HTML, these projects have introduced me to the language and increased my literacy. Before this class I wouldn't have been able to make any sense of an HTML page, but even with the amount of information I have, I feel that I can look at the code for a webpage and actually understand the structure of it, even if I don't grasp all the details.
  2. File management and formatting. I've felt for a long time that I struggled to organize my files in ways that made them easy to navigate and edit, but now I'm being more intentional about the way I organize and name my files.

Lab 3

What I Learned

  1. Basics of CSS rules. Learning about these have allowed me to add a new layer of customization and complexity to my projects. Being able to add colors, fonts, and other element specifications has made my project much more visually interesting and complex. I'm able to see simple lines of text on a page transform into what looks like an actual webpage I might find online. Though I still don't have the interactivity that would come with adding javascript, I feel that I have a much more robust understanding of webpage structure.
  2. The importance of experimentation. Since adding CSS allows more customization and complexity, there are so many interesting things that I can now add to my page's experience. The downside of that freedom is that I made more mistakes that took a longer time to debug, but the process of debugging has strengthened my knowledge.

Lab 5

What I Learned

  1. Basics of CSS layouts. This module goes deeper into the stylizing that CSS gives us. Understanding things like the Box model, floats, grids and flexboxes allows for so much more specificity with the layout of the content. Using these tools I can see my website continually evolve into something that is much more like what I would see on the internet instead of just headings with no interactivity.
  2. We learned more about design principles, not just about the layout and formatting, but the process of effectively working on our designs and the importance of responsiveness in design. Seeing examples of how a web developer works through the actual practice of making his own websites when given content from a client has made it easier for me to layout this project.
