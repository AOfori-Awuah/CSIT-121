The site that I’ve chosen to evaluate today is the site for the Enoch Pratt Free Library. It’s a library here in Baltimore with several branches, established with the express intention of making literacy equally accessible to the “rich and poor without distinction of class or color.” The library continues it’s commitment to service through hosting community building events, sharing information and providing resources to the community

What is the URL of the website?

https.//www.prattlibrary.org

What is the name of the website?

Enoch Pratt Free Library

Who is the site's target audience?

Any community members who are interested in using the library, with a particular emphasis on activities for children.

How is the site organized?

The site has a hierarchical organization. There is a home page with smaller subsections that allow the user to navigate to other areas of the site

Which CRAP Design Principle does the site use? Provide at least one example.

The website’s design makes good use of contrast and proximity. Headings are in large, darker text so that users can quickly scan the page and find information that is relevant to them. The site’s use of proximity allows the users to find related information because it is readily grouped together. For example, on the bottom of the homepage there is a large heading of upcoming programs and events, and the events are grouped together within colored text bubbles that stand out from the page and allow for easy perusal

What is the Audit Score according to the Accessibility Checker?

Unfortunately, the Audit Score from the Accessibility Checker is only 12 for the site

What is the site's effectiveness? Does it help users complete actions accurately?

The site is very effective. The page is designed to maximize the amount of information the user can view without making the design cluttered. Finding the specific information the user would like is simple, and the user can accurately navigate to the content they would like to see.

What is the site's efficiency? Can users perform tasks quickly?

The site’s efficiency is good. The design of the website maximizes the amount of available information and allows fast navigation. For example, when immediately opening the page, right under the main heading the user can find links to the catalog, the event calendar and a map of library locations, which are the most common tasks a user would generally perform.

How is the engagement? Is it pleasant to use and appropriate for its industry/topic?

The website has good engagement. The website uses red as an accent color, in a shade that provides good contrast to the background. The graphics are simple and unobtrusive, and there are no large walls of text that make the site less efficient to peruse. There is enough color to add visual interest without clutter, and the most used links are placed front and center. It seems perfectly appropriate for it’s industry.

Make at least one recommendation to improve this website based on what you learned in this module

The most glaring issue with this site is it’s lack of accessibility. One of the failing elements in the accessibility check was the ARIA elements like links and buttons did not have accessible names , and that many of the hyperlink elements didn’t have meaningful, discernable text content. Addressing these issues would make the website much more accessible
